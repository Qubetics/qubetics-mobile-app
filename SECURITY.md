# Security Policy

## Supported version

Security fixes are made on the `main` branch only.

## Reporting a vulnerability

Do not open a public issue for a security problem. Use GitHub's private
vulnerability reporting (the "Security" tab, then "Report a vulnerability") on this repository.

Please include the affected version or commit, steps to reproduce, and the
impact you expect. We will acknowledge a report within 5 working days and
agree a disclosure date with you once a fix is ready.

## Scope

In scope: the wallet app code in this repository (key handling, signing,
PIN lock, dApp browser, network layer). Out of scope: third-party services the
app connects to, and reports that need a rooted or jailbroken device with
physical access and no further weakness.
